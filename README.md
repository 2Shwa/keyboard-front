# 키덕 (KeyDuck)

## 프로젝트 소개
사용자 성향 기반 기계식 키보드 추천 서비스의 프론트엔드 프로젝트입니다.

## 사용 기술
- React
- CSS
- Figma
- Git

## 담당 역할
- Figma를 활용한 UI/UX 설계
- React 기반 화면 및 컴포넌트 구현
- 키보드 검색 및 필터 UI 구현
- 사용자 편의성을 고려한 화면 및 인터페이스 설계
- Git을 활용한 협업 및 버전 관리

## 프로젝트 목표
기계식 키보드를 잘 모르는 사용자도 쉽고 편하게 자신의 취향에 맞는 키보드를 추천받을 수 있도록 제작한 서비스입니다.
